## 2025-04-01 - Add empty state guidance to hosts-manager TUI
**Learning:** In TUI applications built with Bubble Tea, users can easily feel lost when lists are empty. Empty state messaging needs to be contextually differentiated to clarify whether the overall list is completely empty ("No domains managed yet") versus when a search filter simply yields no results ("No domains match your search"). Additionally, we must adjust the blank space filler loop for pagination to account for the rendered message lines (e.g., set `numRendered = 1`) to prevent layout jumping and preserve exact pagination height.
**Action:** When implementing empty states in paginated lists, explicitly handle empty vs filtered-empty cases, and ensure `numRendered` is adjusted to prevent the UI from shifting vertically.
